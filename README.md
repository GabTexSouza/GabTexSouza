## Projetos em desenvolvimento

Estou construindo um portfólio com projetos novos, organizados para demonstrar competências essenciais em Análise de Dados, BI e Analytics, com foco em problemas reais de negócio.

### 1. Análise de Performance de Vendas com SQL + Python

Projeto focado em análise comercial, criação de KPIs, consultas SQL, análise exploratória em Python e storytelling de negócio.

Principais entregas:
- Modelagem e consultas SQL
- Análise de receita, ticket médio e volume de pedidos
- Análise por região, categoria e período
- Tratamento e exploração dos dados com Python
- Visualizações e recomendações de negócio

### 2. Análise Exploratória de Clientes com Python

Projeto focado em limpeza de dados, estatística descritiva, análise de comportamento de clientes e visualização de padrões.

Principais entregas:
- Limpeza e preparação dos dados
- Análise exploratória com pandas
- Estatística descritiva
- Segmentação inicial de clientes
- Gráficos e insights de negócio

### 3. Dashboard Executivo de Performance no Power BI

Projeto focado em construção de dashboard executivo para acompanhamento de indicadores de negócio.

Principais entregas:
- Modelagem de dados
- Criação de KPIs
- Medidas em DAX
- Visualização executiva
- Análise de performance e recomendações

### 4. Análise de Risco e Inadimplência

Projeto voltado ao setor financeiro, com foco em crédito, risco, inadimplência e perfil de clientes.

Principais entregas:
- Análise de perfil de clientes
- Identificação de padrões de inadimplência
- Estatística descritiva aplicada a risco
- Visualizações para tomada de decisão
- Recomendações para gestão de risco

### 5. Pipeline de Dados Automatizado

Projeto focado em ETL, automação e integração de arquivos para criação de uma base analítica tratada.

Principais entregas:
- Leitura e integração de múltiplos arquivos
- Tratamento e padronização dos dados
- Geração de base consolidada
- Automação com Python
- Documentação do fluxo de dados
